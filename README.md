# Mamacos Voip

Chat, voz, vídeo e compartilhamento de tela com a sua galera. Grátis.

## Como instalar

**Windows — recomendado:** [Microsoft Store](https://apps.microsoft.com/detail/9P12N5S1Q837). Instala sem nenhum aviso do Windows e se atualiza sozinho.

**Windows — instalador:** baixe o **MamacosVoip-Setup.exe** na [página de downloads](https://github.com/Felipe-M-Soares/mamacoVoip-releases/releases/latest). Se aparecer a tela azul "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**. Isso acontece com todo app novo que ainda não tem certificado pago: não é vírus. [Passo a passo com imagens](https://mamaco-voip.vercel.app/baixar/windows?guia)

**Android:** baixe o **MamacosVoip.apk** na [página de downloads](https://github.com/Felipe-M-Soares/mamacoVoip-releases/releases/latest) e abra. Se o celular pedir, permita instalar desta fonte. [Passo a passo com imagens](https://mamaco-voip.vercel.app/baixar/android?guia)

**Sem instalar nada:** use pelo navegador em [mamaco-voip.vercel.app](https://mamaco-voip.vercel.app).

Já tem o app? Ele se atualiza sozinho, não precisa baixar de novo.

Os outros arquivos (*latest.yml*, *.blockmap*) são usados pela atualização automática. Você não precisa deles.
